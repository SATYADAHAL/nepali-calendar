## Initial Stable Release

The first official release of the Nepali Bikram Sambat calendar widget for KDE Plasma!

### Features
- View and navigate Nepali months on your panel
- Clean, simple interface  
- GPL-3.0-or-later licensed

### Limitations
- No direct BS ↔ AD date conversion yet
- Manual month navigation only

### Coming Soon
- Direct date conversion
- Tithis and event display
- More configuration options
