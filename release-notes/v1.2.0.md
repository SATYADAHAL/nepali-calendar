## Date Picker Improvements & Holiday Support

### New Features
- Added holiday support (partial) for Nepali calendar dates
- Improved year and month picker UI for easier navigation
- Added option to show or hide AD (Gregorian) days in the calendar grid

### Notes
- Holiday data is currently partial and will be expanded in future releases
