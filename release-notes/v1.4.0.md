## Tithis, Moon Phases & Panchang

### New Features
- Added Tithi calculation (Shukla/Krishna paksha) using lunar astronomy (sun/moon longitudes, ayanamsa, sunrise)
- Added moon phase icons with 28 phases for the lunar month
- Configurable options to show today's tithi in the header and the moon phase icon
- Tithi name shown on hover for any day in the calendar grid
- Full Nepali/English tithi name support

### Improvements
- Fast panchang calculations with result caching
- Kathmandu-based sunrise computation for accurate tithi determination
- Cleaner header layout with tithi placed next to the moon icon

### Bug Fixes
- Independent toggles for tithi display and moon phase icon in header
- Correct moon phase icon updates when hovering calendar days

### Notes
- Lunar-calendar festival events (Dashain, Tihar, Ekadashis etc.) have been removed from this release
- The original constant/date-based holiday support remains unchanged

### Breaking Changes
- None - fully backward compatible
